# Coffee-Shop-Sales-Analysis
This project analyzes retail coffee shop sales data to uncover customer behavior, sales trends, and product performance. The analysis is visualized in an interactive Excel dashboard with KPIs and insights that drive business recommendations.

Key Highlights:

Sales by store, category, and product
Revenue trends by day, hour, and month
Customer spending patterns
Business recommendations for growth

📊 Tools Used: Microsoft Excel, Pivot Tables, Data Visualization
